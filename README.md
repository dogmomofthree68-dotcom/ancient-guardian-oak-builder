## Layer 8

Build **89 Puffy Tree Pillars** above Layer 7. The **4 red X squares** mark Layer 7 positions that stop before Layer 8. There are no outward additions.

Layer 8 is the final layer where the blocking volume encloses the Pokémon Center. Keep the south entrance open, retain the R10 decorative shelf, and follow the uneven taper so the strongest bark ridges continue while the upper trunk begins narrowing. Branch shoulders do not begin until the next approved layer.
